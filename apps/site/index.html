A self-hosted record of the work you hand to coding agents.

Quorumloop turns a project backlog into tasks for AI coding agents, on your own machine, against your own GitHub or GitLab repositories. Every move a task makes is written down: who moved it, why, which branch it touched, and what the quality gate proved.

Early development. The dashboard, projects, tasks, forge connections and the activity feed work today. Agents do not run yet.

The loop a task goes through

Five lanes, each with a rule about who may move a task out of it. The task service checks every move and refuses an illegal one with the reason, so the history is a list of decisions, not a list of drags.

  1. 01

    Backlog

    An instruction from the composer, or a task you write, lands here.

    Works today

  2. 02

    Ready

    A person promotes it once its acceptance criteria and dependencies are set.

    Works today

  3. 03

    In progress

    Planned: one agent takes a fenced lease on the task and works on its own branch.

    Moved by hand; no agent picks it up yet

  4. 04

    In review

    Planned: a pull request opens and the quality gate runs against it.

    Lane works; the quality service is a scaffold

  5. 05

    Done

    Only reachable when the quality gate reports a pass with evidence.

    Unreachable until the gate exists, by design

Any working lane can move to Blocked with a reason. The reason stays in the task history, next to who wrote it.

Rules the code enforces

One database per service
Each service has its own PostgreSQL database and login role. No service reads another service's tables.
Events through an outbox
A state change and its event are written in the same transaction, then published to NATS JetStream. Consumers drop a redelivered event by its id.
A gateway with no business rules
It checks the browser session and the CSRF token, then forwards a signed call to the service that owns the data.
No invented numbers
A figure appears when a service returned it. Otherwise the dashboard says Unavailable or Not connected.

Run it on your machine

You need Node.js 24 or newer, pnpm 10.20.0, and Docker with Compose v2.

pnpm run setup writes .env with generated secrets. After the last command, open http://localhost:5173; on a new instance the dashboard asks you to create the first admin.

Prefer containers? pnpm compose:core builds the whole core stack and serves the dashboard on http://localhost:8080.

Quickstart, from the repository root 
git clone https://github.com/lexyerresta/quorumloop.git
cd quorumloop
npm install -g pnpm@10.20.0
pnpm install
pnpm run setup
pnpm infra:up
pnpm build
pnpm db:migrate
pnpm dev:core --compiled
